# EcoSort — Household Waste Segregation & Sustainability Web App

EcoSort is a modern, responsive, nature-inspired web application designed to help households segregate waste accurately, establish sustainable daily habits, and eliminate contamination at the source.

## Getting Started Locally

1. Clone or extract this directory:
   ```bash
   cd EcoSort
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for static production hosting (Cloudflare Pages, Vercel, Netlify):
   ```bash
   npm run build
   ```

The production assets will be generated in `dist/`.
